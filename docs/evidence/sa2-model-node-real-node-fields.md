# Real Sonic node field check

Matched all 200 original 0x34 minimum spans and 2600 BE32 fields against the previously validated sample. The sample contains 0 flag0x400 nodes. All original source hashes remain unchanged.

The CSV preserves every raw bit, explicit u32/s32 bit view, low16 ordinary rotation index and binary32 interpretation supported by original lfs instructions. No complete layout, axis/unit or floating-point transform is guessed; +34 is a conditional extension and sample absence cannot validate that mode.
