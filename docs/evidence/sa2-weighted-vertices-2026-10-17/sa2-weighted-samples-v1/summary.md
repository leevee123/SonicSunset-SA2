## Storage order and target selectors

same-stream-packet-order.csv preserves every header encountered by following the encoded next pointer within each independently identified stream, including EOS. same-stream-packet-intersections.csv and same-stream-destination-history.csv report target-selector intersections/repeats in that stored order. This is not a proof that a stream is invoked, that different streams share a live scratch allocation or that node traversal follows file order.

The relative target-selector arithmetic is first_scratch+raw_u16_target for2C and first_scratch+record ordinal for23/29; byte-offset views multiply that index by32. These are relative selectors and do not establish a live base, capacity, initialization or write meaning. Category intersections explicitly distinguish one stored stream from pooled across-stream sets.
